Proyecto desarrollado en Unity 2D utilizando C#, enfocado en la implementación de mecánicas de videojuego y manejo de datos mediante archivos .csv.

📌 Descripción

Este proyecto corresponde al parcial 3 de la Unidad 4 y consiste en el desarrollo de un videojuego 2D en Unity.
Durante el proyecto se implementaron diferentes sistemas de programación en C#, así como el uso de archivos .csv para el almacenamiento y lectura de información dentro del juego.

El proyecto busca aplicar conceptos de:

Programación orientada a objetos
Manejo de archivos
Desarrollo de videojuegos 2D
Uso de Unity Engine
Integración de datos externos mediante .csv
🎮 Características del videojuego
Videojuego desarrollado en 2D
Programación de mecánicas en C#
Lectura de datos desde archivos .csv
Sistema de escenas y niveles
Interacción entre jugador y enemigos
Uso de físicas y colisiones de Unity
